## Проверка интерфейса

CUA: два клиента с раздельными хранилищами `127.0.0.1:5173` и `localhost:5173` в одном браузерном движке. Это независимые origins, а не проверка двух разных браузеров.

- Вход водителя и оператора через API; у operator нет автомобильных полей.
- Учебные телефон и модель сохранены через профиль; после reload восстановлены из БД.
- Название Сокольников временно изменено в PostgreSQL: первый клиент показал его в списке водителя, второй — в маркере настоящей карты. Исходное название восстановлено.
- На localhost настоящая Яндекс Карта отобразила 8 объектов API с подписью Яндекса. На IP-origin включилась подписанная резервная схема; ключ и его ограничения не менялись.
- Проверены фильтры и отсутствие горизонтального переполнения карты на настольной ширине (page=1265, viewport=1280) и 320 px (page=305). Длинный список на компьютере прокручивается отдельно и не растягивает карту; временный размер окна после проверки сброшен.
- Клиентские тесты дополнительно проверяют пустой каталог оператора без автомобиля, неизвестную телеметрию и схему с десятью серверными ID вне локального seed.

Локальный снимок: `artifacts/backend-v01-map.png` в корне проекта (игнорируется Git). Постоянные материалы — этот протокол и автоматические тесты. На GitHub Pages API не развёрнут, опубликованная версия остаётся mock.

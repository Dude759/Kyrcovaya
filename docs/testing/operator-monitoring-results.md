## strict-adjacent-v1

UTC-часы [начало,конец). Дельта энергии учитывается только между последовательными
показаниями с интервалом 0–15 секунд, без gap, внутри одного часа. Конец ровно HH:00
закрывает предыдущий сегмент. Пересекающий границу сегмент не интерполируется:
его известная дельта остаётся unattributed_energy_wh, отдельно от часовой энергии.
Разорванные сегменты также не превращаются в вымышленную почасовую нагрузку.
observed_ms — объединение доверенных интервалов; covered_session_ms — сумма по
сессиям; expected_session_ms — время подтверждённо начатых сессий. Complete требует
полного часа и покрытия всех одновременных сессий без разрывов/границ. Для partial
average_power_w=null, measured_subset_average_w относится только к наблюдаемому
поднабору. Missing означает неизвестные энергию и мощность, а не ноль.
Это консервативная выборка для будущего ML, не полный учёт энергии сессии.

Worker при запуске и раз в минуту пересобирает последние 48 часов; более старые
производные записи сохраняются. PK station/hour и advisory lock защищают повторы.
При одинаковом горизонте неизменные данные не обновляются. В открытом часе ожидаемая
длительность закономерно меняется со временем. Локальный лимит на начало часа/создание
станции восстанавливается по аудиту; смена тарифа не меняет финансовые снимки.

## API / React

GET /operator/monitoring, /monitoring/stations/:id, /monitoring/history,
/monitoring/events, /sessions. Обязательный scope организации; foreign station 404,
driver 403, строгие фильтры, keyset-пагинация, limit 1–100, история до 31 дня.
Чтение в REPEATABLE READ READ ONLY. Старый workspace.networkLimit — конфигурация,
не известный бюджет энергосистемы; новый мониторинг использует gridBudgetKw=null.
HTTP экраны обновляются раз в 10 секунд, скрывают устаревшие показания при задержке.
Полный/неполный/отсутствующий интервал различаются на графике без соединения пропусков.
CSV текущей страницы использует тот же серверный снимок и явно обозначает Вт,
Вт⋅ч, копейки, UTC, source/quality/coverage. Это не кассовый отчёт. Mock сохранён.

## Проверки

M00–M17: миграция, missing, starting, точность источника, 60-секундная граница,
offline, restart/gap без энергии за простой, выделение против измерения, несколько
сессий, UTC-границы, partial/missing, повторная/конкурентная агрегация, исторический
лимит, settlement, фильтры/пагинация/scope, команды и отдельный аудит, настоящий
OS restart, неполнота второй сессии, SQL ограничения организации/качества.
Fault/concurrency только в отдельной PostgreSQL 17 `_test`.
Шесть UI-проверок покрывают неполную сумму, пропуски, pending stop, CSV из снимка,
stale и фильтры. Build и lint проверяются перед публикацией.

Публичный критерий: PR → CI → main → автоматические Render/Pages одного SHA →
smoke → браузер: нет текущих измерений → driver start → operator fresh → ненулевая
энергия → driver stop → точный settlement → reload/login → CSV. QA-сессии и holds
должны завершиться; новые учебные объекты архивируются. Окончательный SHA/статус
выпуска фиксируется в PR после приёмки без повторного deploy ради статуса документа.

## Шаблон прогона

| Поле | Значение |
| --- | --- |
| Дата, commit, среда | Не заполнено |
| Миграции, данные, версии имитаторов | Не заполнено |
| Точная команда / действия браузеров | Не заполнено |
| ID проверки, ожидаемый и фактический результат | NOT RUN |
| Ошибки, логи и ограничения | Не заполнено |

Для I01 указываются число соединений, способ синхронизации, ответы конкурирующих запросов и число резервов/броней в БД. Для распределения сохраняются запросы, ограничения, выделенные и измеренные мощности, время и подтверждения команд. Протокол нагрузки отдельно записывает профиль, длительность, p95 и долю ошибок. Значения не переносятся из примеров проектирования как измеренные результаты.

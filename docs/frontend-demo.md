# Демонстрация фронтенда на защите

Запустите приложение по инструкции `frontend/README.md`. Деморежим работает без сервера и ключа карт. Данные остаются в том браузере и по тому адресу, где выполнялся сценарий.

## Сценарий водителя

1. Откройте главную и объясните назначение сервиса.
2. Войдите как водитель (`driver@energotransport.test`, `Demo12345`) или зарегистрируйте нового водителя.
3. Найдите «Заряд Ходынка», проверьте фильтр разъёма и откройте карточку.
4. Создайте бронь на ближайшее время. Выбранная станция, тариф и разъём должны совпадать с карточкой. Откройте тестовую оплату, покажите ожидание. Нажмите «Проверить отказ», вернитесь к ней через «Брони», повторите и подтвердите тестовую оплату; деньги не списываются.
5. Обновите страницу: бронь должна сохраниться. Начните зарядку из подтверждения/истории. В деморежиме запуск доступен за 15 минут до времени брони.
6. Покажите изменение энергии и стоимости. Раскройте проверку потери связи, отключите её: показания зафиксированы, мощность и оставшееся время скрыты. Восстановите связь и завершите зарядку через подтверждение.
7. Откройте историю сессий и скачайте отчёт CSV. Это отчёт, а не кассовый чек.
8. Измените автомобиль или настройки, обновите страницу и покажите сохранение. Если меняете пароль, запомните его: прежний тестовый пароль перестанет действовать для этого аккаунта.

## Сценарий оператора

1. Выйдите и войдите как оператор (`operator@energotransport.test`, `Demo12345`). Публичной регистрации для этой роли нет.
2. Покажите сводку, журнал и прогноз на сутки. Укажите, что прогноз демонстрационный, а обучение ML-модели — отдельная часть проекта. В проверке состояний покажите ошибку, повтор, отсутствие данных и устаревший расчёт. Закончите успешным обновлением.
3. Выберите станцию, измените лимит, подтвердите действие. Обновите страницу и проверьте новое значение и запись в журнале.
4. Продемонстрируйте сервисный режим и диагностику. Станцию с активной зарядкой нельзя перевести в сервис.
5. Покажите общий лимит сети, распределение и резерв. Лимит ниже суммарного выделения сохранить нельзя.
6. Откройте сессии, переключите статус, скачайте CSV. Можно завершить активную сессию водителя из кабинета оператора.

## Проверки перед показом

Для восстановления доступа откройте ссылку со страницы входа, укажите почту тестового аккаунта и откройте локальную тестовую ссылку. Письмо не отправляется. После смены пароля старый пароль перестанет действовать; запомните новый. Ссылка одноразовая и действует 30 минут, повторный запрос отзывает предыдущую.

- `npm run lint`, `npm run test`, `npm run build` проходят.
- Обновление защищённой страницы сохраняет вход; выход закрывает рабочую область.
- Неверный пароль показывает ошибку; водитель не получает кабинет оператора по прямой ссылке.
- Поиск без совпадений показывает пустой результат; неверный ID станции не открывает другую станцию.
- Проверены телефон и ноутбук, клавиатурный фокус, закрытие диалога по Escape.
- Если нужен настоящий картографический фон, заранее настройте ключ Яндекс Карт и проверьте его на адресе демонстрации. Без него показывается подписанная схема.

На защите корректно отделяйте реализованный фронтенд от будущих интеграций: серверная авторизация, реальные платежи, отправка писем, телеметрия оборудования, ML и управление энергосистемой пока не подключены. Проценты загрузки исходных станций — демонстрационные данные. Локальная энергия моделируется по времени, это не показания счётчика.

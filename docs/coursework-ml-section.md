# Материал раздела «Прогнозирование нагрузки»

Задача: direct 24-hour forecast измеренной мощности, не неограниченного спроса или
команды устройству. [Данные/методика6A](testing/ml-data-readiness-results.md),
[Stage6B все метрики/manifest/границы](testing/ml-model-results.md).

RandomForestRegressor с median imputer fit только train; лаги/статистики учитывают
available_at<=origin. Генератор неизменен, preset выбор по validation предшествовал
однократной финальной оценке test. На11634 общих парах RF MAE53.527863/RMSE75.715506
кВт; weekly116.180936/159.357780; last152.688055/199.321876. Origin перекрываются:
это не независимые физические часы. Преимущество касается синтетической среды,
не достоверности реальной сети или экономии энергии.

Публичный Node API проверяет checksum и воспроизводит immutable исторический
результат с исходным origin; actual NEEDS_MORE_DATA. Нет Python в Node runtime,
онлайн retraining, прогноза на сегодня или ML задания мощности. Grid Dispatch
использует текущие безопасные ограничения/device ack независимо от ML.

Формулировка для защиты: «Модель обучена и оценена на контролируемом synthetic
наборе; сервис воспроизводит сохранённый результат. Actual прогноз требует
накопления полной истории и новой временной оценки». Привести hash/splits/manifest,
метрики24h и release CI/browser acceptance; скриншот сам по себе не доказывает качество.
